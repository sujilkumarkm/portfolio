05 / About

About me.

I’m Sujil Mani, a technology professional with over 10 years of experience across application support, IT operations and web development. I’ve worked with customers, developers, QA teams and specialist support across several countries. I’m now building on that experience through research and hands-on study in agentic AI.

International teams and projects

My career has taken me from web design and development in India to IT operations in the United Arab Emirates and application support in Ireland. In the UAE, I worked across Abu Dhabi, Dubai, Sharjah and Ajman, with exposure to Louvre Abu Dhabi and client environments including Aldar, Al Zeina and Al Muneera. I also worked remotely for Maple Techspace in Canada, developing Laravel and Vue.js applications and coordinating with QA on releases and post-launch fixes.

Team leadership and customer support

My leadership experience includes coordinating incident escalations, explaining business impact and next steps to customers, and working with QA, specialist support, product teams and R&D. I train new colleagues in customer-facing environments through shadowing, reverse shadowing and practical feedback. I focus on giving each team the evidence it needs to act and keeping customers informed as an issue moves between teams.

Application support and security

I troubleshoot application outages, endpoint connectivity and integration failures by analysing backend and device logs, checking DNS and firewall rules, querying databases, and testing REST and SOAP requests. I use Datto RMM for remote monitoring and management, work with patch and software policies, and triage security alerts in Datto EDR and RocketCyber. My IT support experience also covers Windows devices, Active Directory and virtual desktop environments.

Software development and web design

I build web applications with JavaScript, Vue.js and PHP using Laravel. My earlier work included Java and JSP applications, and I use Python for web development and data analysis. On the frontend, I use HTML and CSS with Bootstrap and Tailwind CSS to build responsive layouts and interfaces. At Maple Techspace, I developed Laravel and Vue.js features and refined layouts based on user feedback.

Database management and data architecture

I use SQL with MySQL and SQL Server to work with relational data. My experience spans MySQL-backed web applications, database queries for application support, and SQL investigations into data and access issues. I bring a data architecture perspective to this work by considering how data is structured, how applications and integrations use it, and how those choices affect reporting and troubleshooting.

Business systems, Git and deployment

I’ve worked with IFS, Autotask PSA, Salesforce and Jira across business operations, customer support and issue tracking. I use Git with GitHub and Bitbucket to manage code changes. I also deploy websites to live production servers using cPanel, where I’ve configured domains, Python environments, application settings and HTTPS. This Django portfolio is one example of that work.

Data analytics and machine learning

During my Level 9 Master’s in Data Analytics at Dundalk Institute of Technology, I built Python Dash dashboards and created visualisations with Excel, Power BI and Tableau. My research covered time-series analysis and machine learning. In application support, I use SQL to investigate data and access issues and check what the evidence says about a reported fault.

Agentic AI and entrepreneurship

I’m currently taking a course in agentic AI and exploring how cloud services and models from Google Gemini and OpenAI can support responsive, automated agents. I’m interested in building production-ready assistants that answer questions, find relevant information and help teams handle routine tasks. An “Ask AI” feature for this portfolio is one way I plan to put that learning into practice.

My long-term ambition is to lead a technology company as CEO and use AI to improve how businesses operate. I want to build tools that reduce repetitive work and give teams more time for issues that need human judgment.
